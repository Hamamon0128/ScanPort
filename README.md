# Advanced Port Scanner (GUI)

Python 標準ライブラリのみで動作する  
高機能 GUI 付き TCP ポートスキャナ。

教育用途・自己管理ネットワークの診断を目的としたツール。

---

## 主な機能

- TCP ポートスキャン（指定範囲）
- スレッド数制限による高速スキャン
- スキャン進捗表示（何ポート中何件チェック済み）
- 経過時間表示
- スキャン中断機能
- スキャン完了を1回だけ正確に通知
- ローカル IP アドレス自動検出
- 開放ポート一覧表示
- CSV / JSON 形式で結果保存
- GUI + ターミナル両方にログ出力

---

## 動作環境

- Python 3.8 以上
- Windows / macOS / Linux
- 追加ライブラリ不要（標準ライブラリのみ）

---
